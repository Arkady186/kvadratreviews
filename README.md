# ASD — отзывы и наши работы

Сайт без своего сервера: работает на GitHub Pages. Отзывы хранятся в бесплатном Supabase.

Страницы (у каждой своя ссылка, её можно отправлять отдельно):

| Страница | Что это |
|---|---|
| `index.html` | Главная |
| `works.html` | Наши работы. Ссылка на раздел: `works.html?c=kuhni` (`shkafy`, `sanuzly`, `tv-zony`, `ofis`) |
| `reviews.html` | Отзывы и форма (1 отзыв с 1 устройства) |
| `quiz.html` | Опросник «Дизайн-проект мебели для вашего дома» (5 шагов, файлы, имя и телефон) |
| `admin.html` | Админка: заявки из опросника и проверка отзывов (вход по почте и паролю) |

## 1. Фото работ

1. Скачайте облака Mail.ru в папки внутри проекта:
   - `photos/kuhni/` — Кухни
   - `photos/shkafy/` — Шкафы
   - `photos/sanuzly/` — Санузлы
   - `photos/tv-zony/` — ТВ-зоны
   - `photos/ofis/` — Офисная мебель
2. Подразделы делаются подпапками: `photos/kuhni/угловые/…` — на сайте появится кнопка «угловые».
3. Запустите `python tools/process_photos.py` (нужен Python и `pip install pillow`).
   Скрипт сожмёт фото в `img/works/` и обновит `js/works-data.js`.
4. Папка `photos/` с оригиналами в GitHub не попадает (она в `.gitignore`).

## 2. Хранилище отзывов (Supabase, бесплатно)

1. Зарегистрируйтесь на supabase.com → **New project** (имя любое, регион ближайший, придумайте пароль базы).
2. **SQL Editor → New query**: вставьте содержимое `supabase/schema.sql`, нажмите **Run**.
3. **Authentication → Users → Add user → Create new user**: ваша почта и пароль, галочка **Auto Confirm User**.
4. В SQL Editor выполните (со своей почтой): `insert into public.admins(email) values ('ваша@почта.ru');`
5. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**.
6. Вставьте их в `js/config.js` в `supabaseUrl` и `supabaseAnonKey`. Ключ anon публичный, его можно показывать: защита задана правилами в базе.

Пока ключи не вставлены, на сайте виден «Демо-режим»: отзывы хранятся только в браузере.

## 3. Публикация на GitHub Pages

1. Загрузите папку проекта в репозиторий.
2. **Settings → Pages → Deploy from a branch → `main` / `(root)`** → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как работает «1 отзыв с 1 устройства»

- Браузер получает случайный номер устройства и хранит его сразу в трёх местах (память страницы, cookie, IndexedDB). База не принимает второй отзыв с тем же номером.
- Если человек очистит **всё** (все данные сайта) или откроет другой браузер или телефон, он получит новый номер и сможет оставить ещё один отзыв. Полностью запретить это без входа по телефону/почте нельзя ни на каком сайте.
- Поэтому отзывы публикуются после вашей проверки (`admin.html`), а для повторов есть пометка «Похожее устройство уже оставляло отзыв».
- От массовой накрутки напрямую в базу защищает ограничение: не более 15 новых отзывов за 10 минут на весь сайт.

## Контакты и название

Всё в `js/config.js`: название компании, телефон, WhatsApp, Telegram, ссылка на каталог техники.

## 3. Заявки из опросника (один раз)

1. Supabase → **SQL Editor → New query**: вставьте содержимое `supabase/leads.sql` → **Run** (должно быть «Success»).
   Скрипт создаёт таблицу заявок и закрытое хранилище файлов `lead-files` (до 10 МБ на файл, фото и PDF).
2. Откройте `admin.html`, войдите: вкладка **Заявки** покажет имя, телефон, ответы и прикреплённые файлы.
3. Заявки можно переводить в «В работе» и «Завершённые», оставлять заметки и удалять (файлы удаляются вместе с заявкой).

Файлы видит только администратор: в хранилище они закрыты, а в админке открываются по временным ссылкам.


## Поддержка сайта и «один опрос с устройства»

1. Supabase → **SQL Editor → New query**: вставьте содержимое `supabase/support_and_once.sql` → **Run**.
2. Что это даёт:
   - в подвале каждой страницы кнопка **«Поддержка сайта»**: посетитель описывает ошибку, сообщение попадает в **Админка → Ошибки**;
   - опросник можно пройти только один раз с устройства (метка хранится в трёх местах браузера и проверяется на сервере).
3. Чтобы самому заново пройти опрос для проверки: очистите данные сайта в браузере или откройте сайт в другом браузере.
